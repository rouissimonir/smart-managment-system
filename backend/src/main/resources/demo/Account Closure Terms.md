# Account Closure Terms

Ending a subscription is a subscription termination.

Termination takes effect at the end of the current billing period. Fees already
paid for that period are not returned. Open projects owned by the account are
marked cancelled when the termination date is reached. Export any documents
before that date; stored files are deleted 14 days later.

This document does not describe refunds. See the separate refund policy for money
already paid.
